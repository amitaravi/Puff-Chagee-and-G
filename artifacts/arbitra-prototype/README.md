# Arbitra standalone prototype

Open `prototype.html` in any modern browser. It is a single-file interactive artifact:
all styles, case data, analysis, interactions, and the architecture view are embedded.
It requires no server, API key, package install, or network connection.

Presentation controls:

- Select any of the four use cases from the left docket.
- Switch between **Case file**, **Court timeline**, and **Judicial analysis**.
- Use the left and right arrow keys to move through cases.
- Scroll to the architecture and corpus-proof sections for the closing narrative.

The editable architecture source and standalone SVG live in `docs/architecture.mmd`
and `docs/architecture.svg`.
